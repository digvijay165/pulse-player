# Pulse

**A bright, browser-based music discovery player.** Search tracks, play short previews, build a queue, and keep favorites on your device.
LIVE:https://pulse-player-0rdw.onrender.com/
## Features

- Search songs and artists through the iTunes Search API
- Play short audio previews with playback, seek, volume, repeat, and shuffle controls
- Build and clear a listening queue
- Save favorite tracks in the browser's local storage
- Browse by genre and use a responsive layout on phones and desktops
- No account or installation required

## Run it

Open `index.html` in a modern browser while connected to the internet. Pulse loads its track catalog and artwork from Apple's public iTunes Search API. Preview availability varies by track and region; previews are short samples, not full-length streaming.

## Privacy

Favorites are stored locally in your browser. Search requests go directly to the iTunes Search API; Pulse does not run its own server or account system.
